САЙТ BAUDET — ПРЕДВАРИТЕЛЬНАЯ ВЕРСИЯ

1. Сначала распакуйте архив целиком.
   Windows: правый клик по архиву → «Извлечь все…» → «Извлечь».
   Mac: двойной клик по архиву.
2. Откройте распакованную папку baudet-site-preview
   и дважды кликните файл index.html.
3. Нужен интернет — фото товаров и шрифты подгружаются из сети.

Не открывайте index.html прямо внутри архива, не распаковав его —
тогда страница будет пустой.

Каталог и корзину можно смотреть. Кнопка «Оформить заказ»
заработает после запуска сайта на хостинге.
